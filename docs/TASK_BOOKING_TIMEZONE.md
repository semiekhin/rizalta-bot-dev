# Задача: Онлайн-показы с часовыми поясами

📅 **Создано:** 26.01.2026
🏷️ **Статус:** В работе

## Проблема

1. Фиксированные слоты (10:00, 11:00...) — нужен свободный ввод времени
2. Нет часовых поясов — Алтай (UTC+7) vs Москва/Сочи (UTC+3), разница 4 часа
3. В заявке только @username — нужны имя, телефон, что показываем
4. Автозапись в секретарь — время может меняться после созвона

## Решение

### Новый flow
```
[Записаться на показ]
    ↓
📅 Выбор даты (кнопки) — как сейчас
    ↓
⏰ Ввод времени текстом: "10:30" (по Алтаю)
    ↓
🕐 Подтверждение: "14:30 Алтай / 10:30 Мск"
    ↓
📱 Контакт (request_contact или из профиля)
    ↓
📝 "Что показываем?" (текст)
    ↓
✅ Подтверждение → заявка в группу
```

### Новая таблица: user_profiles
```sql
CREATE TABLE user_profiles (
    user_id INTEGER PRIMARY KEY,
    name TEXT,
    phone TEXT,
    timezone TEXT DEFAULT 'altai',  -- 'altai' | 'moscow'
    created_at TEXT DEFAULT CURRENT_TIMESTAMP,
    updated_at TEXT
);
```

### Изменения в таблице bookings
```sql
ALTER TABLE bookings ADD COLUMN realtor_name TEXT;
ALTER TABLE bookings ADD COLUMN realtor_phone TEXT;
ALTER TABLE bookings ADD COLUMN show_description TEXT;
ALTER TABLE bookings ADD COLUMN timezone TEXT DEFAULT 'altai';
```

### Формат заявки в группе (новый)
```
🆕 Новая заявка на онлайн-показ

📅 29 января (Чт)
🕐 14:30 (Алтай) / 10:30 (Мск)

👤 Иван Петров
📱 +7 999 123-45-67
💬 @ivan_realtor

📝 Корпус 2, студия 25м², бюджет 5 млн

🆔 Заявка: #19

[👨‍💼 Взять заявку]
```

### После «Взять заявку» (новое)
```
✅ Вы взяли заявку #19

Добавить в секретарь?

[📅 Да, время 14:30]
[✏️ Да, другое время]
[❌ Не добавлять]
```

При «Да, другое время» → ввод нового времени → запись в секретарь.
